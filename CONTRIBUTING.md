# Contributing

Спасибо за интерес к проекту!

## Как внести изменения

1. Форкните репозиторий и создайте ветку под задачу.
2. Следуйте структуре монорепо (`apps/`, `packages/`).
3. Описывайте изменения в PR и прикладывайте скриншоты для UI‑правок.

## Стиль и качество

- Пишите понятные имена и краткие функции.
- Проверяйте локальный запуск API и web перед PR.
- Не коммитьте секреты — используйте `.env.example`.
